# Task 2 - Exploratory Data Analysis (EDA)

## Objective

The objective of this task is to understand data using statistics and visualizations.

## Dataset

Titanic Dataset

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Plotly

## EDA Performed

1. Generated summary statistics including mean, median, and standard deviation.
2. Created histograms for numerical features.
3. Created boxplots to understand distributions and identify outliers.
4. Created a correlation matrix to study relationships between numerical features.
5. Created a pairplot to visualize relationships between features.
6. Identified patterns, trends, and anomalies from the visualizations.
7. Made basic feature-level inferences from the analysis.

## Key Learning

- Descriptive statistics
- Data visualization
- Correlation analysis
- Pattern recognition
- Anomaly detection
- Feature-level analysis
